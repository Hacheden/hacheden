# Hacheden

Сайт-бар: анимированная барная стойка, история напитков, читальня со свечой и курилка времён сухого закона.

Сайт: https://hacheden.netlify.app

## 3D-версия

Отдельная страница: https://hacheden.netlify.app/3d/ — настоящая 3D-комната на Three.js, камера перелетает между стойкой, курилкой и читальней.

- Сцена лежит в `3d/js/*.js` (склеиваются по порядку имён), разметка — в `3d/src.html`.
- `python3 tools/build3d.py` собирает `3d/index.html`: данные напитков, карточки, музыку, книгу рецептов, крупный план и барную карту он берёт из основного `index.html`, поэтому обе версии всегда совпадают.
